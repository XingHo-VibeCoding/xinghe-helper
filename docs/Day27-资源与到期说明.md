## 四、导出数据的操作步骤（备查）

> ⚠️ **今天没有实操导出**（清单「今日不做」范围外）。以下是按 CloudBase 体验版的路径写的，**第一次用请先拿测试环境试**。

### 4.1 导出数据库数据

**路径**：控制台 → 云数据库 → 数据库列表 → 点进数据库 → 工具/数据导出

**要导什么**（4 张表）：

| 表 | 内容 | 重要度 |
|---|---|---|
| `students` | 学生报名数据 | 🔴 最不能丢 |
| `rooms` | 房间信息 | 🔴 |
| `camps` | 营期 | 🟡 |
| `assignment_history` | 分配历史 | 🟡 |

**表结构**已经在仓库里了（`db/schema.sql`），所以**结构不用导，只需要导数据**。

### 4.2 导出云函数代码

代码在 git 里，不需要额外导出。用 tag 就能拿到任意版本：

```bash
git checkout v1.0 -- cloudfunctions/
```

### 4.3 导出静态托管

```bash
MSYS_NO_PATHCONV=1 npx --yes --package @cloudbase/cli tcb hosting download / ./backup-hosted -e xinghe-helper-d5g92pis442fd9947
```

> ⚠️ 不加 `MSYS_NO_PATHCONV=1`，Git Bash 会把 `/` 转成它自己安装目录的路径 —— **Day 23 就是这个坑导致站点根目录被覆盖**。

### 4.4 ⚠️ 一个大坑

**代码能从 git 导出，数据不能。**

git 里只有 `db/schema.sql`（建表语句），**没有真实数据**。数据只存在于云数据库里，**导不出来就真没了**。

所以真要接真实数据，**第一件事不是做功能，是把数据导出这条路走通一次**。
