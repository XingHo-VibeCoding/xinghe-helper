## 六、回答「敢不敢用」

**敢。理由是演练验证了三个环节都能靠得住：**

1. **还原靠 git，不靠记忆。** `git checkout v1.0 -- <文件>` 一条命令，不用回想"当时改了什么"。
2. **构建可复现。** 产物哈希与原版一字不差 —— 这条是"回滚是不是真的回滚了"的判据。
3. **37 秒可恢复。** 站点坏掉到恢复，中间只有 37 秒。这个数字现在知道了，真出事就不用慌。

**但也有三个前提，必须记住：**

- **tag 必须提前打。** 项目此前一个 tag 都没有 —— 现在有 `v1.0` 和 `v1.0-rc1` 两个可退点。
- **源码在 tag 里，产物不在。** 所以回滚是「取回源码 → 重新构建 → 重新部署」，不是「传回旧文件」。多了一步构建，也就多了 4.5 秒。
- **云函数回退没练。** 今天只练了静态托管（清单明确「今日不做」）。真出事时云函数要另外单独处理。
